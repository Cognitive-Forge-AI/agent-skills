# Blueprints project memory

The `blueprints` skill maintains relevant Specs, Decisions, and optional Explorations under the project's adopted rules. It loads the drafting or maintenance procedure per item, and reads retained history only when a connection or an explicit question needs it.

Bundled here: suite version 0.2.0-preview.1, the consumer specifications under `references/blueprints/` (generated from the framework sources), and the discovery, drafting, and maintenance procedures. [SKILL.md](SKILL.md) is the entry point.
