# Select profiles

Read only profiles selected by the user or needed to resolve the brief. Each file owns defaults for one axis. Resolve links relative to this reference. Explicit requirements outrank defaults within higher-priority instructions; incompatible mandatory rules need a choice. Preserve voice and regional spelling. With no selections, use the capability's own defaults.
