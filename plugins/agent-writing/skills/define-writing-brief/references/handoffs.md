# Writing handoffs

Read only the section needed for the current handoff. These are compact field conventions, not mandatory saved documents. Omit empty fields. Use prose or a small list for simple tasks; retain supplied IDs and locators.

## Context

- Sources: ID, path or supplied label, locator, coverage/version when material.
- Facts: claim, source IDs and locators, qualification.
- Source claims: attribution and verification status; distinguish unsupported from contradicted.
- Assumptions: inference and basis, separate from facts.
- Unknowns: missing or conflicting information and effect on writing.

## Brief

- Audience and prior knowledge; purpose and intended outcome.
- Scope and required content; source/context IDs.
- Constraints: voice, regional spelling, length, locked wording/examples, format.
- Profiles: axis, ID/path, scope; read selected files before applying them.
- Assumptions or unresolved conflicts.

## Outline

- Section or unit; reader purpose; supporting source IDs; gaps.
- Order dependencies and locked headings when relevant.

## Review

- Location: heading, paragraph, line, or exact identifying excerpt.
- Problem and impact.
- Evidence or rule, with source locator/profile reference.
- Concrete repair; priority when useful.
- Coverage and limitations, including unsupported versus incorrect claims.

Each capability can use these fields directly if this shared reference is absent. A handoff conveys facts and constraints; it does not activate another skill automatically.
