# Markdown conventions

Use the requested renderer's supported Markdown. Default to one document title when a title is needed, then logical heading levels without skipped hierarchy. Use sentence case unless the brief or established publication convention requires another capitalization. Preserve proper names and identifiers.

Use bold sparingly for useful emphasis or labels and italics for terms or titles where appropriate. Selected technical text conventions narrow emphasis within technical passages. Use inline code for short literal tokens and fenced blocks for multiline or executable samples, with a language label when known. Preserve exact code; choose fences that do not terminate inside the sample.

Use numbered lists for ordered steps and bullets for parallel items. Separate headings, paragraphs, lists, and fences with blank lines. Use tables for genuine comparisons. Give links descriptive labels and images useful alt text; decorative images may use empty alt text. Use callouts only when supported by the renderer, otherwise a labelled paragraph.
