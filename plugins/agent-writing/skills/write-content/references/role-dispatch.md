# Dispatch writing roles

Load this reference only for role-based drafting or review. Resolve each link relative to this file. Use native subagents when available and authorized; names may be plugin-qualified by the host. Read the role file before dispatch and pass its instructions or its resolvable installed path.

- [Writer](../../../agents/writer.md): drafting or adaptation.
- [Structural editor](../../../agents/structural-editor.md): coverage, progression, assumptions, navigation.
- [Style editor](../../../agents/style-editor.md): humanizer audit or authorized prose repair.
- [Factual reviewer](../../../agents/factual-reviewer.md): claims and examples against evidence.

Choose independent reviewers in proportion to complexity and consequence; a paragraph edit normally needs none. Give each reviewer the artifact, brief/requirements, selected profile paths and scopes, and relevant sources. Exclude the writer's self-assessment, prior conclusions, and expected findings. Request the location/problem/evidence/repair finding format. Collect findings, repair material issues, and recheck affected concerns.

If native subagents are unavailable, apply the same selected role files sequentially in the current conversation. Keep the artifact and requirements visible for each pass, avoid using a writer self-assessment as evidence, and state that the review was sequential rather than independent. Do not duplicate role procedures here or treat skill UI metadata as an agent definition.

For a single-skill installation with no role files, perform the requested capability directly and identify the missing role if it was explicitly requested. Do not invent a native agent registration or install global configuration.
