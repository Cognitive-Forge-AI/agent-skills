# Humanizer

Rewrite, draft, or audit prose so it sounds like the author. The skill removes
stiff, generic generated phrasing while preserving facts, meaning, commitments,
and the level of formality the writing needs.

Ask the assistant to use `humanizer` with your text, for example:

> Use humanizer to rewrite this email in my voice. Keep the facts and commitments.

Rewrites and drafts return the finished prose. Audits identify the strongest
problems and suggest specific fixes. The skill improves writing quality and
voice; it makes no claims about AI detector results.
