# Plain professional

Use direct, specific prose suited to the author's professional register. Prefer familiar words and active verbs when they preserve meaning. Explain specialized language when the audience needs it, while keeping technical terminology that carries a precise distinction.

State the useful point early, then develop the evidence or detail needed to assess it. Cut empty framing, inflated claims, and repeated conclusions. Vary sentence shape where repetition becomes mechanical; retain deliberate parallelism that helps the reader.

Match formality to the brief. Professional writing can use contractions or a restrained personal voice when the author does. Do not invent personality, anecdotes, enthusiasm, or certainty. Preserve regional spelling and user-defined voice above these defaults. This profile governs prose choices, not information architecture or Markdown emphasis; those rules come from the selected structure and presentation.
