# Structure writing

Organize material around what the reader needs to learn, do, find, understand, or assess. Use the supplied brief and context; do not create new facts to fill an outline.

## Procedure

1. Identify the reader's task, prior knowledge, required coverage, and constraints. For a supplied draft, locate gaps, misplaced information, repetition, and hidden prerequisites before rearranging it.
2. Read only the selected structure profile under references/profiles: [tutorial](references/profiles/tutorial.md), [how-to](references/profiles/how-to.md), [reference](references/profiles/reference.md), [explanation](references/profiles/explanation.md), or [argument](references/profiles/argument.md). Read a selected medium profile only if its publication setting affects the outline. With no profile, choose a progression suited to the stated reader task and name that assumption only when material.
3. Assign each section a purpose and the facts or sources it needs. Put prerequisites before dependent steps, definitions before unfamiliar usage, and decisions near the information supporting them. Keep lookup material consistently organized. Distinguish learning exercises from instructions for an experienced reader's goal.
4. Preserve required headings, exact examples, normative wording, and scope. If a requested reorganization would change meaning or violate a locked structure, flag the conflict. Link to a separate explanation or reference when that keeps the main task coherent; do not invent a destination.
5. Check progression from the reader's starting point through the intended outcome. Mark missing coverage or evidence as a gap, not a completed section. Scale the outline to the artifact; a paragraph may need only a reordered sentence.

## Output and composition

Return the requested outline, reorganized draft, or structural findings. For an outline handoff, read [handoffs](../define-writing-brief/references/handoffs.md), outline section only; if unavailable, use section, purpose, and source/gap fields directly.

This skill owns information order. It does not apply a universal chapter length or dictate heading syntax. For prose changes, read [humanizer](../humanizer/SKILL.md) before using it; for markup changes, read [format-writing](../format-writing/SKILL.md). Do not load either for an outline-only request.
