# Tutorial

Lead a beginner through a supported learning experience with a clear endpoint. State what they will practise and the prerequisites they need before starting. Choose a reliable path through the exercise rather than presenting every option at each step.

Order actions so each one builds on completed work. Give commands or examples enough context to execute safely in the stated environment, and describe observable results from the supplied evidence. Let the learner check progress before depending on it. Include a supported recovery hint where a likely mistake would stop the exercise; do not invent tool behaviour.

Keep explanations close to the action only when they help the learner continue. Move deeper theory or complete API detail to existing related material. Finish at the learning outcome, with an optional supplied practice variation. Give a check for the variation’s result when the sources support it. The tutorial structure does not set tone, renderer, or a code-block limit.
