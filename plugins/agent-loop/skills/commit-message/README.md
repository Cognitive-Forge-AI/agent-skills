# Commit Message

Write a concise Conventional Commit-style message from a diff, staged changes,
working-tree changes, or a change summary. The skill follows project-defined
commit conventions and uses a scope only when the project explicitly defines it.

Ask the assistant to use `commit-message`, for example:

> Use commit-message to write a commit message for my staged changes.

The result is a short subject line, with a body or footers only when the context
calls for them. See [SKILL.md](SKILL.md) for the full instructions.
